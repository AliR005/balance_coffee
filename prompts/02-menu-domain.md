# 02 · Меню и цена (backend)

Режим: сначала Plan, после OK — Build.
Прочитай `AGENTS.md`, `docs/SPEC.md` (разделы 4, 5.1–5.3, 6).

## Цель
Домен меню и точек, seed из YAML, публичный API меню, расчёт цены и валидация выбора с покрытием тестами.

## Что сделать
1. **Модели и миграции:** Location, Category, Product, OptionGroup, ProductOptionGroup, Option, LocationProductAvailability, LocationOptionAvailability (см. SPEC, раздел 4). Деньги — `int`.
2. **Seed:** файл `backend/seed/menu.yaml` и команда `make seed` (идемпотентная, безопасно запускать повторно).
   - 2 точки с реалистичными часами работы, часовым поясом, `slot_capacity`, разным стоп-листом.
   - Категории: Кофе, Молочные, Холодные, Без кофеина.
   - Около 12 напитков: эспрессо, американо, капучино, латте, флэт уайт, раф, мокко, колд брю, айс латте, какао, матча-латте, чай.
   - Группы опций: размер (S 200 / M 300 / L 400 мл, цены −30 / 0 / +60), молоко (коровье, безлактозное, овсяное, миндальное, кокосовое; альтернативные +50), сироп (ваниль, карамель, лесной орех, солёная карамель; 0–2), доп. шот (0–2), температура (где применимо). Для молочных напитков молоко обязательно.
   - У молока и сиропа заполни `visual` (например `{"liquid": "oat"}`), фронт использует это для чашки.
   - Цены в комментарии YAML отмечены как «демо, заменить реальными».
3. **API:**
   - `GET /locations` (с полем `is_open_now` по часам работы и часовому поясу).
   - `GET /locations/{id}/menu`: категории → продукты → группы опций (min/max, обязательность, значения по умолчанию) → опции. Недоступное по стоп-листу возвращается с `available: false`, а не скрывается.
   - `POST /locations/{id}/quote`: принимает позиции, валидирует и возвращает цену по позициям и итог.
4. **Логика:** `PriceCalculator` (чистая функция) и `SelectionValidator`, правила из SPEC 5.1–5.3. Коды ошибок из SPEC.
5. **Клиент:** `make gen-api`, убедись, что типы меню появились в `web/`.

## Тесты (обязательны)
Цена без опций, с опциями, с отрицательной дельтой (размер S), с количеством; границы min/max в каждой группе; пропущенная обязательная группа; опция чужого продукта; недоступный продукт и недоступная опция на одной точке, но доступная на другой; неактивный продукт; лимиты количества; `is_open_now` на границах часов работы и при разных часовых поясах.

## Границы (не делай)
Заказы, слоты, staff, любой UI, кэш, админку, загрузку фото.

## Критерии готовности
`make seed && make test && make lint` зелёные; три эндпоинта видны в OpenAPI; `/menu` двух разных точек различается стоп-листом.

Отчёт по формату из AGENTS.md. Приложи пример JSON ответа `/menu` для одного напитка.
