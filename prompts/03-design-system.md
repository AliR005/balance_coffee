# 03 · Дизайн-система на фронте

Режим: сначала Plan, после OK — Build.
Прочитай `AGENTS.md`, `docs/DESIGN.md` полностью, `design/tokens.css`, открой `design/preview.html` как визуальный эталон (карточки, окно напитка, оформление, бонусы, старт, статус). Если можешь запустить браузер или сделать скриншот, сверяй результат с эталоном на каждом компоненте.

## Цель
Набор компонентов на токенах и страница просмотра, чтобы дальше собирать экраны без изобретения стилей.

## Что сделать
1. Токены: подключи `design/tokens.css` (скопируй в `web/src/shared/styles/`), замапь на Tailwind v4 через `@theme`. Шрифты Onest и Caveat локально через `@fontsource`. Светлой темы нет (только сливочная панель через токены `--panel*`).
2. Примитивы: `Button` (primary с градиентом `--primary` → `--primary-2`, ghost, loading без скачка ширины), `IconButton` (в том числе стеклянный), `Chip`, `Segmented`/`SizeButtons`, `Stepper`, `Switch` (`role="switch"`), `Sheet` (drag-to-close, фокус-ловушка, Escape, safe area), `Skeleton`, `Toast`, `PriceText` (tabular, `Intl.NumberFormat`, roll-анимация), `TabBar` (плавающая пилюля), `Logo` (inline SVG на `currentColor`).
3. **`BrewView`**: рисованный «ролик» приготовления, вид сверху (SVG + CSS-анимация): чашка, кофе, струя молока, рисунок. Варианты рисунка: `heart`, `tulip`, `full` (со сливочной поверхностью), `crema` (без молока). Props: `variant`, `milkColor`, `durationSec`, `paused`. Цвета из токенов. Эталон анимации и геометрии — в `design/preview.html` (функции `brew` и `artOf`). Ролик играет только у видимых элементов (IntersectionObserver), при `prefers-reduced-motion` показывает финальный кадр.
4. **`BrewVideo`**: если у напитка есть `video_url`, рендерит `<video muted loop playsinline autoplay poster>`, иначе `BrewView`. Единый интерфейс для обоих.
5. **`LiveCard`**: карточка напитка по разделу 5 DESIGN (свечение, затемнение, бейдж длительности, полоса прогресса, круглая «+», состояние «Закончилось»).
6. **`DrinkPlayer`**: верх окна напитка (ролик, кнопки, пауза, прогресс, время) и чипы шагов, подсвечиваемые по ходу ролика.
7. **`BonusRing`** (кольцо и счётчик), **`Glass`** (стакан со льдом и зёрнами для hero и старта, по `preview.html`), **`Splash`** (брызги молока из логотипа один раз).
8. Страница `/dev/ui` (только dev-сборка): все компоненты во всех состояниях, переключатель `prefers-reduced-motion`.
9. Тесты vitest: `PriceText`, `Stepper`, логика подсветки шагов по времени.

## Границы (не делай)
Экраны приложения, запросы к API, корзину, роутинг кроме `/dev/ui`. Не вводи цвета и радиусы вне токенов. Не оставляй стили shadcn по умолчанию.

## Критерии готовности
- `/dev/ui` совпадает с `design/preview.html` визуально.
- Фокус виден, всё доступно с клавиатуры. Проверено на 360 и 390 px.
- В компонентах нет hex-значений (проверь grep-ом). `make lint` и `make test` зелёные.

Отчёт по формату из AGENTS.md. Приложи список компонентов и их props.
