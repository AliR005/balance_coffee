# DESIGN — balance (v2)

Токены: `design/tokens.css`. Живой макет всех экранов: `design/preview.html` (открыть в браузере, карточки и «ролики» анимированы, объём, молоко, время и бонусы кликабельны). Логотип: `design/assets/logo-b.svg` (заглушка, ждём вектор от клиента).

## 1. Идея

Интерфейс тёмный, как обжаренное зерно, а красками служит сам кофе: молочная пена, карамель, медь. Экран не спорит с напитком, он даёт ему свет. Всё, что можно показать напитком, показываем напитком, а не рамкой и подписью.

Два фирменных приёма:
1. **Живая карточка.** За каждым напитком стоит маленький ролик его приготовления: вид сверху, три шага (эспрессо, молоко, рисунок). На карточке он крутится по кругу без звука, в окне напитка его можно смотреть и ставить на паузу. На экране заказа человек видит, как готовят именно его напиток.
2. **Баланс.** Название в интерфейсе работает буквально: объём и молоко меняют напиток на экране, а бонусное кольцо, слоты и уровни всегда показывают, «сколько до». Молочные брызги из логотипа проигрываются один раз на старте.

Характер: тёплый, спокойный, немного кинематографичный. Минимум рамок и декора, много воздуха, крупные цены и названия.

## 2. Цвет

| Токен | Значение | Роль |
|---|---|---|
| `--bg` | #0C0A09 | фон приложения |
| `--surface` / `--surface-2` / `--surface-3` | #171412 / #201B18 / #2B2521 | карточки, поля, неактивные элементы |
| `--text` / `--text-2` | #F5ECE4 / #A99B91 | текст |
| `--primary` → `--primary-2` | #F3D8C3 → #E6BF9F | главная кнопка (градиент сверху вниз), выбранные чипы |
| `--on-primary` | #24170F | текст на персиковом |
| `--accent` / `--accent-text` | #C58C67 / #E0B48C | медь из логотипа, акцентные слова, иконки |
| `--panel` (+ `--panel-text`, `--panel-solid`) | #F7EDE4 / #2A1F1B | светлая «сливочная» панель оформления заказа |
| `--success` / `--danger` | #8FC2A0 / #E58A78 | баллы, ошибки |
| `--glow` | медь 30% | свечение под напитком |

Правила:
- Главная кнопка на экране одна: персиковая. Тёмные экраны без неё не бывают.
- **Оформление заказа на светлой сливочной панели**: платёж и время читаются как «документ». Выбранный вариант на панели: тёмный (`--panel-solid`) с кремовым текстом. Итог заказа: тёмный блок с персиковой кнопкой.
- Свечение `--glow` только под напитком (карточка, окно, hero). Градиентов больше нигде, кроме кнопки и бонусного кольца.
- Контраст текста ≥ 4.5:1. `--text-3` только для неактивного и декоративного.
- Светлая тема во всём приложении в MVP не делается (в BACKLOG).

## 3. Типографика

**Onest** для всего (300, 400, 500, 600). **Caveat** только для подписи-акцента («найди свой баланс»), один-два раза на экране старта и hero.

| Роль | Размер | Вес |
|---|---|---|
| Hero (десктоп) | 58 / 1.05, трекинг −0.025em | 300, вторая строка `--accent-text` |
| Заголовок экрана | 30 | 400 |
| Название напитка | 30 (окно), 16 (карточка) | 400 / 600 |
| Цена крупная | 30 | 600 |
| Текст | 14–16 | 400 |
| Мелкое | 11–13 | 400–500 |
| Номер заказа | 34 | 600 |

Цены и время всегда с `tabular-nums`. Заголовки лёгкие, цены и кнопки плотные: этот контраст даёт ритм.

## 4. Форма и слои

Радиусы по ролям: кнопки, чипы и переключатели — пилюля; поля 16; строки и панели 20; карточка напитка 24; итог заказа 28; окно видео 36 снизу. Слои разделяются тоном и тонкой линией `--line`. Тень нужна только плавающим элементам. Стекло (`--glass-bg` + размытие) допускается только у элементов поверх видео и у нижнего меню.

Нижняя навигация: плавающая пилюля с четырьмя пунктами (Главная, Меню, Бонусы, Профиль), активный пункт персиковый.

## 5. Компоненты

- **LiveCard** (карточка напитка): соотношение 3:4, видео/ролик на весь фон с тёплым свечением, снизу затемнение и подпись (название, описание в 2 строки, цена, круглая персиковая «+»). Сверху справа стеклянный бейдж «▶ 0:09» с длительностью. По нижней кромке тонкая полоска прогресса ролика. Недоступный напиток: приглушён, вместо цены «Закончилось», «+» нет.
- **BrewVideo**: видео `muted loop playsinline autoplay` с постером. Пока видео нет, используется рисованная анимация `BrewView` (вид сверху: чашка, кофе, струя молока, рисунок). Воспроизводится только видимое, при `prefers-reduced-motion` и экономии трафика показывается постер.
- **DrinkPlayer** (окно напитка): ролик на верхние ~340 px, кнопки «назад» и «звук» стеклянные, снизу пауза, прогресс и время. Под роликом чипы шагов («1 Эспрессо», «2 Молоко», «3 Рисунок») подсвечиваются по ходу ролика. Ниже: категория, название, описание, крупная цена с «+N баллов», объём (три крупные кнопки), молоко и сиропы (чипы с цветной точкой), плавающая нижняя панель «Добавить в заказ» и «В избранное».
- **Реакция на выбор**: объём меняет масштаб чашки, молоко перекрашивает пену, цена и бонусы пересчитываются сразу.
- **ModeSwitch**: два больших варианта «На месте» и «На время». На время открывает выбор слота: чипы «Скорее» и слоты по 10 минут, занятые зачёркнуты и недоступны. На месте: текст «Готовим сразу. Ориентир — около N минут».
- **LocationRow**: точка, часы работы, шеврон. В шапке меню та же точка пилюлей.
- **BonusRow / Switch**: «Списать N баллов» с переключателем в оформлении. Итог показывает «Бонусами −N ₽» и «+M баллов».
- **BonusRing**: кольцо на 210 px с числом баллов, градиент персик → медь, заполняется при появлении экрана; ниже карточка уровня с полосой прогресса, «Как зарабатывать», «История».
- **OrderStatus**: код заказа, ролик приготовления, статус и время, линия стадий, состав, начисляемые баллы.
- **Стёпперы, чипы, сегменты** — пилюли, область нажатия ≥ 44 px.

## 6. Экраны (эталон — `design/preview.html`)

1. **Меню.** Шапка: логотип, точка, корзина. Заголовок «Выбери свой кофе», подпись. Блок «Повторить» с прошлым заказом. Чипы категорий (фильтруют, пустая категория показывает текст). Сетка карточек 2×N.
2. **Напиток.** Ролик, шаги, описание, объём, молоко, добавить.
3. **Оформление** (светлая панель). Режим, точка, время, позиции со степпером, бонусы, итог, «Заказать на 10:30», способ оплаты («При получении», онлайн-оплата позже).
4. **Бонусы.** Кольцо, уровень, как зарабатывать, история, «Потратить бонусы».
5. **Старт.** Логотип «b» с брызгами молока, большой стакан со льдом и зёрнами, подпись «найди свой баланс», «Заказать» и «Меню».
6. **Мой заказ.** Ролик, код, статус, линия стадий, позиции, баллы, отмена (недоступна после начала приготовления, с объяснением).
7. **Сайт (десктоп hero).** Логотип и меню, крупный заголовок, стакан со льдом и зёрнами в центре, «Смотреть, как мы готовим», три преимущества внизу: заказ ко времени, заказ на месте, бонусы.
8. **Экран баристы** (планшет, отдельный режим): три колонки (Новые, Готовятся, Готовы), крупные кнопки, срочность цветом и текстом. Без декоративного движения и без видео: читаемость важнее красоты.

## 7. Движение

Самопроизвольно движутся только: ролики, стакан на hero и старте, пульс кнопки «смотреть». Остальное реакция на действие.

| Что | Как |
|---|---|
| Ролик приготовления | цикл 7–12 с: ряби эспрессо, струя молока, рисунок, пауза, сброс |
| Выбор объёма/молока | масштаб и цвет с пружиной, 500 мс |
| Кнопка «+» | сжатие 0.88 и счётчик на корзине появляется с пружиной |
| Переключатель режима, слоты | смена заливки 250 мс |
| Бонусное кольцо, полоса уровня | 1,6 с при первом показе, число считается от 0 |
| Брызги молока | один раз на старте, ~1,6 с |

Нет: параллакса, бесконечных декоративных движений, fade-in на каждом блоке. Ролики играют только когда видны и приостанавливаются вне экрана. `prefers-reduced-motion`: ролики заменяются постером, счётчики без анимации.

## 8. Ролики: требования к съёмке и файлам

- Формат: MP4 (H.264) и WebM, без звука, 4:5 (720×900), 6–15 секунд, до 1,5 МБ, бесшовная петля.
- Постер JPG/WebP на каждый напиток, показывается сразу.
- Единый стиль: вид сверху, один свет, один тёмный фон и посуда, три шага. Один кадр-стиль на все напитки важнее красоты отдельного ролика.
- Поля данных: `video_url`, `poster_url`, `video_duration_sec`, `video_steps` (подписи и времена шагов для чипов).

## 9. Тексты

Русский, обычный регистр, простые глаголы.

| Где | Текст |
|---|---|
| Меню | Выбери свой кофе · Каждый напиток — маленькая история. Смотри, как он готовится. |
| Действия | Добавить в заказ · Заказать на 10:30 · Повторить · Потратить бонусы |
| Режимы | На месте: Заберу сейчас · На время: Укажу время |
| Время | Когда забрать · Сегодня. «Скорее» — около 10:20. |
| Стоп-лист | Закончилось |
| Слот занят | Это время только что заняли. Выберите другое. |
| Нет связи | Нет связи. Пробуем снова, заказ не потерян. |
| Отмена | Отмена недоступна: напиток уже готовится. |
| Бонусы | +18 баллов · Начислим, когда заберёте заказ |
| Оплата | Оплата при получении · Онлайн-оплата появится позже |
| Бренд | найди свой баланс · Кофе к твоему приходу |

## 10. Доступность
Контраст ≥ 4.5:1; область нажатия ≥ 44 px; фокус виден; у видео есть пауза и подпись `aria-label`; состояние передаётся не только цветом; переключатель бонусов — `role="switch"`; ролик не запускает звук; проверка на 360, 390, 768, 1024 px.

## 11. Чего избегаем
Светлых фонов вне панели оформления; сеток одинаковых карточек без видео; стокового фото вместо единого стиля съёмки; тяжёлых градиентов и неона; декоративного движения; иконок вместо текста в главных действиях.
