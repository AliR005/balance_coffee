# DEMO — сценарий показа клиенту (5 минут)

## Подготовка
```bash
make reset-demo   # секунды: чистит заказы/слоты/бонусы, сеет меню, печатает PIN и QR
```
Открой на телефоне клиентскую ссылку (или QR из терминала), на планшете — ссылку баристы.

## Чек-лист за час
- [ ] Интернет и зарядка на обоих устройствах; звук на планшете включён.
- [ ] `make reset-demo` выполнен последним (чистые слоты и коды заказов).
- [ ] Приложение добавлено на экран телефона (PWA).
- [ ] PIN баристы под рукой (печатает `make reset-demo`).
- [ ] Проверен стоп-лист для демо: колд брю недоступен на Тверской.
- [ ] Время на устройствах верное (слоты считаются от текущего времени).

## Запасной план
- Нет сети: заранее записанное видео сценария (сними один чистый прогон).
- Упал сервер: `docker compose up --build` заново + `make reset-demo`; если не помогло — веди по видео.
- Занятые слоты: `make reset-demo` освобождает всё за секунды.

## Вопросы клиенту (SPEC, раздел 9)
1. Страна и валюта; когда нужна онлайн-оплата и какой провайдер.
2. Реальные меню, цены, составы, молоко и опции.
3. Адреса точек, часы, реальная пропускная способность слотов.
4. Логотип в SVG, брендбук (сверить `--copper`), фото напитков.
5. Нужны ли аккаунты и накопительная программа сверх демо-бонусов.
6. Языки интерфейса.
